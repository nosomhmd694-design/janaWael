01 / INTRODUCTION

What is CSS?

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML documents.

01
✳

Definition

CSS is a style sheet language used to describe how HTML elements should be displayed. It controls colors, fonts, spacing, backgrounds, and page layouts.

02
✦

Importance

CSS makes websites attractive and easier to use. It helps developers create consistent designs and responsive layouts for different devices.

03
⌘

How it works

CSS selects HTML elements and applies visual rules to them. These rules tell the browser how each element should look.

02 / CSS METHODS

Three ways to style.

There are three main ways to add CSS to an HTML page.

01

Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute. 

<p style="color: purple;">Hello</p>
02

Internal CSS

Internal CSS is written inside a style element in the head section of an HTML document. 

<style>
h1 { color: purple; }
</style>
03

External CSS

External CSS is written in a separate CSS file and connected to the HTML document. 

<link rel="stylesheet" href="style.css">
Best Practice: External CSS is usually the best choice for large websites because it keeps the design organized and reusable.
03 / CSS PROPERTIES

Important Properties.

CSS properties control different visual aspects of HTML elements.

Property Purpose Example
color Changes text color color: purple;
background-color Changes background color background-color: black;
font-size Changes text size font-size: 20px;
font-family Changes font style font-family: Arial;
margin Adds outside spacing margin: 20px;
padding Adds inside spacing padding: 15px;
border-radius Rounds element corners border-radius: 10px;
04 / RESPONSIVE DESIGN

One website.

Responsive design allows websites to adapt to different screen sizes, including mobile phones, tablets and desktop computers.

        font-size: 24px;
